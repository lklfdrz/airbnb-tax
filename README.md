# 에어비앤비 호스트 세무 계산기

에어비앤비 한국 호스트의 매출 CSV를 업로드하여 국세청 신고 기준 매출과 예상 세액을 자동 산출하는 서비스.

## 기능

- CSV 업로드 → 매출 정제 (Payout/기타 크레딧 자동 필터링)
- 매출 인식 시점 선택 (체크인일/거래일/입금예정일)
- 부가세 추정 (간이/일반과세 자동 분기)
- 종합소득세 시나리오 비교 (단순경비율/기준경비율/장부신고)
- 가산세 시뮬레이션

## 면책

본 서비스가 산출하는 세액은 참고용 추정치이며, 실제 세무 신고를 대체하지 않습니다.
